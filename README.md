# YOLOanything

## 全球冰雹灾害图谱（Global Hailstorm Hazard Atlas · 2016–2026）

一个浅色主题、带导航栏的单页交互式应用：把公开的多源冰雹灾害资料整合成可查询的
「国家 × 事件 × 指标」图谱，用于科普、研究与风险沟通。

### 功能

| 模块 | 说明 |
| --- | --- |
| 概览 | 关键指标卡片（事件数、涉及国家、最大冰雹、伤亡、可统计损失）+ **全球速览**（最昂贵 / 最大冰雹 / 最多伤亡 / 事件最多 / 累计损失最高 / 覆盖度，均可点击跳转）+ 主要结论 |
| 全球地图 | **50m 精度 Natural Earth 底图**（world-atlas 50m，失败回退 110m）+ **美/中/澳省州界叠加**（us-atlas 10m、cn-atlas 34 省、world-geojson 澳洲 7 州）+ 五种指标色阶（事件数 / 综合严重度 / 最大冰雹直径 / 经济损失 / **风险等级**，后者用绿→红色阶覆盖含无事件国家的 66 个国家/地区）+ 事件气泡（大小 = 冰雹直径，颜色 = 年份），可标注「仅有风险备注」的国家，点击国家查看国家档案 |
| 国家排行 | 前 12 位条形图 + 可排序的国家明细表（事件数、最大直径、伤亡、损失、严重度），可切换「包含仅有风险备注的国家」把覆盖度扩展到 66 个国家/地区；下方为**按区域对照表**（六大洲 × 国家数/事件数/伤亡/最大冰雹/可统计损失/最大与最贵事件） |
| 时间演变 | 年度事件数（按区域堆叠）、年度最大冰雹直径、各国/各数据库官方年度序列（11 组） |
| 国家速查 | 全部 66 个国家/地区的卡片视图（风险等级、事件数、最大冰雹、伤亡、损失、趋势摘要），支持按国家名/ISO 代码搜索与按风险、事件数、损失排序 |
| 事件库 | 关键词检索 + 年份/区域/直径/伤亡筛选 + 多种排序 + 分页；点击行打开事件档案弹窗（含定位小地图与原始出处链接）；**一键导出当前筛选结果为 CSV** |
| 科学认知 | 11 张同行评审文献结论卡片（全球热点、损伤潜力、地中海增势、致损尺寸阈值、作物风险迁移、欧美机制差异等）与 25 条历史极值对照（含超出十年窗口的纪录，用于尺度参照） |
| 数据与方法 | 22 个数据源清单、方法学（遴选标准、严重度评分、金额口径、50m+省州界渲染方式）、6 类已知局限 |

### 数据

- **事件**：**145 起**重大冰雹事件（2013、2016–2026），覆盖 **55 个国家/地区**（第三轮巴西 Erechim 10 cm/Florianópolis 3,200 栋/印度比哈尔61死/曼尼普尔15,425栋 + 第四轮南非豪登省午夜雹暴/肯尼亚基苏木50户/泰国北部5府/印尼茂物/尼日利亚Jos 等 19 起新增），每条记录包含
  日期（含精度等级：日 / 月 / 季 / 多日）、经纬度、最大冰雹直径、死亡/受伤、经济损失、
  保险损失、严重度评分（1–5，含复合事件降级规则）、摘要、详述与来源链接。
- **国家备注**：**67 个国家/地区**的风险等级、趋势、要点统计与参考来源；其中 13 个在
  近十年窗口内没有事件级记录（数据缺口会被明确标注，而不是留空）。
- **省州级钻取**：支持美/中/澳/巴/印/阿等国的州省分布（基于 region 关键词匹配），在国家档案面板中展示省州级事件数、最大冰雹、伤亡与损失条形图。
- **年度序列**：ESWD（欧洲）、NOAA SPC（美国）、中国应急管理部（风雹）、Guy Carpenter（日本）、
  ICA（澳大利亚）、State Farm（美国单一保险公司冰雹理赔）、澳大利亚重大雹暴保险损失，
  以及逐国补充序列（美国、澳大利亚、巴西、中国）。
- **历史极值**：25 条，覆盖美国州级最贵雹暴序列、德国 1984/2013、澳洲 1999/2025、
  南非、欧洲单季损失与报告纪录、日本单年损失等。

主要来源：NOAA/NWS SPC、NOAA NCEI 十亿美元级灾害、ESWD/ESSL、EM-DAT、
Munich Re NatCatSERVICE 与 Hail Research 2025、Swiss Re Institute sigma、
PERILS / CatIQ / ICA / IBC / VNV / Consorcio、Gallagher Re、Guy Carpenter、Aon、
中国应急管理部与中国气象局、Cotality、State Farm、各国气象与灾害管理机构，
以及 Nature、Nature Geoscience、Nature Climate Change、Nature Communications、
NHESS、Weather、Atmospheric Research、Frontiers in Environmental Science 等同行评审文献。
完整清单与口径说明见应用内「数据与方法」章节。

### 运行

```bash
# 依赖（仅为离线打包前端库与测试所需；应用本身不需要构建）
npm install

# 启动本地静态服务器（浏览器打开 http://localhost:8000）
npm run serve

# 无头冒烟测试（需要先启动上面的服务器）
npm run smoke
```

> 页面通过相对路径加载 `web/vendor/` 下的 d3 与 Natural Earth 底图，**不需要任何 CDN**，
> 可直接离线使用。请通过 http 打开（`file://` 下浏览器会阻止读取本地 JSON，此时地图会
> 显示降级提示，其余模块仍可用）。

### 已知局限（详见应用内说明）

- 冰雹数据是「观测 + 报告」的产物：美国、欧洲、日本等报告密度远高于非洲、南亚与中亚，
  **国家间数量差异不等于真实风险差异**。
- 「直接经济损失」「保险损失」「受灾人口」等来自不同体系，不可互相换算或相加。
- 历史数据仍在修订（ESWD 迟报质控、保险损失多次更新）；死亡人数通常被低估，
  多数死亡来自伴随的强风、房屋倒塌与洪涝。
- 极端冰雹直径纪录受「发现概率」影响；单一事件不可归因于气候变化。
