# 多模态修正轮测试报告（R7 召回修复 + R8 YOLO26-seg × Depth 融合）

**日期**：2026-09-24　**触发**：用户贴 R6 失败证据（R-C 曲线 all≈0.01、val_batch2_pred 近空）+ 指令「检测错误必须修正，必须使用 yolo26 seg × depth 多模态」「禁止无中生有合成数据」

## 1. R6 失败根因

从零 4ep×40% 短训严重不足：R6 终值 mAP50(B)=**0.00472**、mAP50-95(B)=0.00095、P=0.760/R=0.0217；
mask mAP50=0.006。R-C 曲线 all classes≈0.01、val 预测近空属训练不足，非管线 bug。

## 2. 修正方案（双管齐下）

| 轮次 | 方案 | 配置 |
|---|---|---|
| R7 | RGB 热启动全量续训修召回 | r6/best 热启动 **844/844 迁移**，6ep×100% @320 SGD lr0=0.008 cache=disk |
| R8 | 多模态：DepthLite 伪深度与 RGB 融合成 Y-D-S 三通道重训 | fused 数据（ch0=S,ch1=D,ch2=Y），r7 热启动，6ep @320 SGD lr0=0.006 |

**数据合规（用户铁律）**：DepthLite 训练数据已合规重建——`real_depth`（背景=真实 ROV 帧+物理成像变体，
目标=真实标注实例抠取变换，**标签同步迁移 4424=4424 0 丢失**，深度 GT=摆放物理）；
旧程序化假场景（syn_depth）已删除（见 子任务4 报告合规修正节）。
**浏览器侧融合**：`composeFusedSource`（Y-D-S 合成，通道序对齐训练管线）+ `depthGate`（深度门控评分融合），
模型选择器按 manifest `preprocess:"yds"` 识别融合模型。
