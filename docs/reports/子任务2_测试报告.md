## 2. 预处理流水线（scripts/preprocess.py）

清洗（解码校验/标签合法性/越界裁剪）→ 类别映射保留16类 → **按类别签名分层抽样**划分 → 可视化 → dataset.yaml（含 trash_ids 语义标注）→ 可选离线增强。

三种增强策略变体（Loop Hardness 对比）：
| 变体 | 配置 | 定位 |
|---|---|---|
| v1_base | 翻转+亮度±18%, scale 0.5-1.5 | 基线 |
| **v2_water（选定）** | +高斯模糊25%/噪声20%/蓝绿色偏(水体红光吸收)/scale 0.4-1.6/旋转3° | 水体真实感 |
| v3_strong | 亮度±30%/模糊35%/噪声30%/scale 0.3-1.8/旋转6° | 强增广压测 |
