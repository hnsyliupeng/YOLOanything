## 实现要点（app/js/core/relations.js）

- **SEM_PROTO**：16×16 语义原型（人造物/有机物/金属/塑料/织物/纸质/木质/橡胶/危险/可回收/漂浮/大型/细长/块状/设备/生物）
- `buildRelationGraph(dets, srcW, srcH, {simTh=.86, distTh=.22})`：
  - 语义边：原型余弦相似 ≥0.86 → same-kind（同类）/ same-family（同族）
  - 空间边：IoU>0.25 → contains / overlap；中心距 <0.22 → near / above / below / left-of / right-of
- `sma3Enhance(dets, graph)`：并查集对 same-kind 边分簇 → 簇内 box 向簇均值收缩 30%、score 融合（0.7·自身+0.3·簇均值）、标注 enhanced/clusterSize
- `graphSummary()`：节点/边计数、簇数、top 边列表（UI 深度理解面板直接呈现）
