**环境级缺陷记录（影响后续所有子任务的测试基线）**：
- Chromium 153 dev + SwiftShader 存在 **GPUDevice 持续 destroyed 缺陷**（连渲约3帧即丢设备，`mapAsync` 报 "A valid external Instance reference no longer exists"）。应用已实现指数退避自动恢复；像素级验证采用 **CDP截图像素统计（端到端）** 为主、GPU回读为辅的双层方案。真实 Chrome/Edge 硬件 GPU 无此缺陷（预期≥60fps）。
